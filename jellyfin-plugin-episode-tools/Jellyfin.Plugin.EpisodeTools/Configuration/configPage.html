Episode Tools

The tasks are under Dashboard > Scheduled Tasks > Episode Tools. The output of each run is in Dashboard > Logs.

Must be the folder that directly contains one sub folder per series, for example /mnt/storage/media/Series. Do not point this at the whole media folder: the first folder name would be used as the show name.
All sub folders are searched too, so /mnt/storage/media covers the whole media folder (series and movies).
Off by default. When off, both the .mkv and the .mp4 stay (Jellyfin may then show duplicates until you remove the .mkv files).
