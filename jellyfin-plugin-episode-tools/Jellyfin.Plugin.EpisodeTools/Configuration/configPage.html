These settings are read by the tasks each run. The output of every run lands in Dashboard > Logs.

Folders

Rename folders must directly contain one sub folder per series (up to five). Scan folders are searched recursively for .mkv files (up to five).

Conversion

Files are only converted when at least this much space is free on the destination (default 10). Protects full drives.
Off by default. When off, both the .mkv and the .mp4 stay (Jellyfin may then show duplicates until you remove the .mkv files).
On: the MP4 index is moved to the front of the file, which writes the whole file a second time (safe for progressive web downloads). Off: each file is written once — about twice as fast, half the wear. Jellyfin streams with range requests, so playback works fine without faststart. Turn this off if conversion feels slow.

Audio & subtitles

On: files with such audio are no longer skipped. Only those audio tracks are re-encoded to AAC (5.1 at 448k, stereo at 192k); the video is copied untouched and AAC tracks stay as they are. Off: those files are skipped. If you also delete the .mkv, the original lossless audio is gone for good.
On: subtitle tracks titled signs, songs, lyrics, karaoke or titles are left out of the MP4 when a dialogue track exists — players otherwise show song lyrics flashing over the picture. Off: all tracks are kept. Check which episodes are affected on the Sub Check tab.
On: subtitle tracks whose text is mostly numbers, ad/spam lines or OCR junk are left out when a better track exists. Requires python3 on the server; skipped silently when it is missing.

Performance & playback

On by default: conversions wait between files and intro scans wait between season groups while someone is actually watching something. Off: background work always runs (it still runs at low priority). Nothing is cancelled by playback — work simply waits and resumes.

Notifications

When set, a POST request is sent here after every convert run finishes (apply mode). Works with ntfy.sh, Discord (via a relay) or your own script. Leave empty to disable.

Intro scanning

The fast intro scanner is run from the Intros tab or with the "8. Scan intros (fast)" scheduled task. It only fingerprints the first few minutes of each episode, decodes several episodes in parallel and caches results per file.
How much audio at the start of each episode is fingerprinted (default 4). Intros always live in this window; scanning later parts of an episode is wasted work. Raise it only when episodes have very long openings after cold opens.
How many ffmpeg processes decode episodes at the same time (default 2). 2 is gentle on a 4-core Raspberry Pi; 3–4 finishes faster.
Audio ranges shorter than this are ignored (default 15).
Audio ranges longer than this are ignored (default 120). Raises it for shows with very long openings.
Off by default. On: a second scan pass fingerprints the last minutes of each episode, matches credits across the season's episodes and publishes them as Outro segments (skip credits buttons). Results appear in the Intros tab.
How much audio at the end of each episode is fingerprinted for credits (default 4). Raise it only when episodes have very long credits after the last scene.

Manual intro overrides

Fixed intro windows for shows where the automatic detection drifts (variable cold opens). Show is required; season (S01) and episode (a file name fragment like S01E06) narrow the match; start and end are seconds. Matched episodes skip detection entirely, so rescans never clobber these values. One show/season row applies the same window to every episode.

Shows

Every show found in your series/scan folders. Choose the default subtitle language and default audio language per show — they apply the next time that show is converted: matching tracks are kept and flagged as the default for players.
